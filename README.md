# Rodbegbie Tap

## How do I install these formulae?

`brew install rodbegbie/tap/<formula>`

Or `brew tap rodbegbie/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rodbegbie/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
